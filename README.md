# CSEC 520/620 — Project Template

Starter repository for CSEC 520/620 (Cyber Analytics & Machine Learning) projects.
It enforces the course **reproducibility standard**:

> A grader can recreate your results from your repository in **one command**.

Stack: **Python + PyTorch**. Minimal setup — a plain `venv` and `pip`, nothing else.

Requires Python 3.10+ and `make`.

---

## Quick start

```bash
# 1. Create a virtual environment and install deps
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
# (or just: make setup)

# 2. Reproduce results  <-- this is the grading command
make reproduce        # == python -m src.train --config config.yaml
```

`make reproduce` trains the model and writes to `results/`:
`metrics.json`, `confusion_matrix.png`, `roc_curve.png`, and `model.pt`.

The template ships with a **synthetic dataset**, so it runs before you add real data.

### Using Keras

Keras 3 is included and runs on the **PyTorch backend** (no TensorFlow needed).
Select the backend *before* importing Keras — either set the environment variable:

```bash
export KERAS_BACKEND=torch      # add to your shell, or prefix the command
```

or, at the very top of a script, before `import keras`:

```python
import os
os.environ["KERAS_BACKEND"] = "torch"
```

(If you prefer the TensorFlow backend instead, `pip install tensorflow` and set
`KERAS_BACKEND=tensorflow`.)

## Repository layout

```
├── config.yaml         # all knobs live here (edit this, not the code)
├── Makefile            # setup / reproduce / test / lint / clean
├── requirements.txt    # minimal pip dependencies
├── src/
│   ├── data.py         # load & prepare data (train-only scaling — no leakage)
│   ├── model.py        # PyTorch model
│   ├── train.py        # single entry point: python -m src.train
│   └── evaluate.py     # metrics + figures (confusion matrix, ROC)
├── data/               # NOT committed — see data/README.md
├── results/            # regenerated by `make reproduce`
├── report/             # IEEE-format final report
├── tests/              # smoke tests (pytest)
├── grading/            # agent-gradable: rubric + auto harness + protocol
└── .github/workflows/  # CI: lint + tests + a sanity reproduce run
```

## Grading (by an AI agent or a human)

This repo is designed to be graded by an agent. See `grading/`:

- `grading/rubric.yaml` — machine-readable rubric (weights sum to 100).
- `grading/grade.py` — objective check harness. Run `python grading/grade.py`
  to produce `grading/auto_report.json` (structure, tests, reproduce, metrics,
  leakage scan, report presence, git hygiene).
- `grading/AGENT_GRADING.md` — the protocol an agent follows to turn those checks
  plus qualitative judgment into `grading/grade.json` + `grading/grade_report.md`.

Before submitting, fill in `SUBMISSION.md` and make sure `python grading/grade.py`
looks clean.

## Using your own dataset

1. Put download instructions in `data/README.md` (don't commit the data).
2. Set `data.source: csv` and `data.csv_path` in `config.yaml`.
3. `make reproduce`.
